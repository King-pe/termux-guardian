# Security Policy

## Supported versions

The `main` branch is the supported development line. Releases will be announced by MrCodex1Tz in the official repository.

## Report a vulnerability

Do not open a public issue for an unpatched vulnerability. Contact the repository owner through the private security contact configured in GitHub, or use GitHub's private vulnerability reporting if enabled. Include reproduction steps, affected files, impact, and a safe mitigation.

## Safety boundary

The project intentionally does not read or display Wi-Fi passwords, tokens, keys, cookies, or other credentials. Reports suggesting credential extraction as a feature request are out of scope and will be closed. Network diagnostics must remain limited to safe metadata and authorized recovery guidance.
